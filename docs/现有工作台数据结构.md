# 现有工作台数据结构速览

## 核心实体

| 实体 | 代码位置 | 用途 |
|---|---|---|
| `HardwareProject` | `web-app/src/data/projects.ts` | 整机项目身份、版本、进度、摘要和根 SR 路径 |
| `CSRDocument` | `web-app/src/types.ts` | 一个 CSR 文档的版本、单元、管理拓扑和 Objects |
| `ManagementTopology` | `web-app/src/types.ts` | Anchor、Bus、Chip、Connector 的管理链路 |
| `BoardTopologyModel` | `web-app/src/types.ts` | 将 CSR 转换为板卡、设备、连接器和关联线 |
| `AgentTask` | `web-app/src/components/AgentTerminal.tsx` | 关键词、任务、工具轨迹、输出、结果和关联视图 |
| `PaneNode` / `TabEntry` | `web-app/src/App.tsx` | 多 Tab、多 Pane 的工作区布局状态 |

## 状态分类

- 工程状态：当前项目、当前文件名、是否脏数据。
- CSR 状态：已加载、未加载、修改、保存/下载。
- 任务状态：运行中、完成、失败。
- 页面状态：当前活动 Tab、分屏比例、AI 面板、终端 Dock。
- 环境状态：BMC 可达数、SSH、Docker、问题数等状态栏摘要。

## 关键关系

```text
HardwareProject → rootSrPath → CSRDocument
CSRDocument → ManagementTopology + Objects
AgentTask → viewId → 关联功能页
当前工程 → 可用能力提示 → 活动栏/更多菜单
```
