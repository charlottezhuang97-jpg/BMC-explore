# 现有工作台接口与入口契约

## 用户入口

| 入口 | 载荷/状态 | 去向 |
|---|---|---|
| 选择项目 | `HardwareProject` | 加载 root SR、设置当前工程、打开拓扑 |
| 上传文件 | `.sr/.json` 文本 | 解析 CSR、设置文件名、打开拓扑 |
| 欢迎页 Agent 输入 | 文本命令 | `postMessage({type:'ai-run-agent', cmd})` |
| 快捷能力按钮 | 固定 Agent 命令 | AgentTerminal 任务匹配 |
| 视图卡片/活动栏 | `viewId` | 打开 Tab 或分屏 |
| CSR 编辑保存 | 当前 `CSRDocument` | VS Code `saveContent` 或下载文件 |

## Agent 消息契约

- `ai-run-agent`：把任务发送给父级工作台终端。
- `ai-open-scenario`：任务完成后打开关联视图。
- `ai-open-web`：在安装向导旁打开登录/密钥等页面。
- `ai-open-history`：进入 Agent 历史。
- `ai-close-panel`：关闭 AI 面板。

## 设计注意

当前入口契约的中心是 `viewId` 和命令字符串，而不是持久化的任务实体。Q4 如果优化任务流，需要补充任务 ID、当前阶段、前置条件、执行结果、失败原因、下一步和恢复入口。
