贡献者：charlottezhuang97-jpg

原型：同目录 `csr-adaptation-lowfi.html`，可离线直接打开；不依赖远程脚本或三维模型。

## 本轮要验证什么

飞船参考解决“看见工作对象”：从整机定位板卡，从板卡定位器件，再关联管理配置。

电路板参考解决“看见专业操作”：AI 依据资料操作配置、遇到不确定性停下、保留人工决策、重新校验并交付结果。这里只借鉴操作深度，不设计 PCB。

两条方向共享同一任务上下文、选中对象、配置版本和操作权；不是两个互相独立的展示页。

## v0.2：独立对照窗口，而非互斥标签

- 默认并列打开物理结构和 CSR 拓扑；配置草稿可以同时打开。三个窗口各有标题与关闭入口。
- 顶部复选框表示“哪些窗口已打开”，不是“当前切到哪一个页面”；至少保留一个工作窗口。
- 左右对照时两个窗口并排，全部打开时配置草稿放在下方；支持上下排列。窄屏自动上下排列，保留所有已打开窗口。
- 选中器件时，部件树、模型、已有对应拓扑节点和草稿的对照对象联动。不存在对应节点时不冒充匹配。
- 接管时补开拓扑与配置草稿，但不关闭已有物理窗口。修改总线即时同步到拓扑与草稿，并标记“未保存修改”；取消恢复已保存值。
- 窗口开关和排列不会清空草稿、任务记录、视角或选中状态。当前版本只在本次页面会话中保留，刷新会重置。
- 自由拖拽停靠、弹出独立浏览器窗口和可拖拽分隔线暂未实现，不作为本版能力承诺。

## 首个任务的边界

- 用户：板卡适配工程师。
- 任务：依据 Rev.B 资料适配示例 FanBoard，并生成候选 CSR 交付物。
- 输入：硬件连接资料、旧版 CSR、匹配的对象模型与校验规则。原型全部使用示例数据。
- 关键决策：旧版上级映射 I2C-7 与新资料 I2C-6 不一致，用户需要确认资料适用性或接管配置草稿。
- 输出目标：候选配置、相关上级映射说明、校验报告、用户决策与输入来源。
- 不包含：PCB 布局布线、完整 PSR 整机集成、真实签名、部署和实机验证。
- 重要边界：更改上级 Connector 映射不等于改板内物理接线，也不一定只涉及本板 CSR 文件。正式实现必须明确变更文件和跨板影响范围。

## 方向 A：整机与部件检查器

| 粒度 | 用户要理解的问题 | 首版交互 | 与任务的关联 |
| --- | --- | --- | --- |
| 整机 | 风扇板在哪里，与哪些部件相邻？ | 示意整机、部件树、拆解滑杆、视角预设 | 当前任务对象高亮 |
| 板卡 | 板内有哪些被管理器件？ | 进入风扇板、点选 EEPROM / 温度传感器 | 显示选中器件的业务说明 |
| 管理关系 | BMC 经什么连接访问板内对象？ | 并列打开 CSR 拓扑，展示上级 Connector → Anchor → 器件 | 定位需要确认的连接映射 |
| 配置 | AI 实际改了什么？ | 同时打开配置草稿，查看前后值与依据 | 与拓扑、记事板和审阅页共享候选值 |

物理视图提供实体 / 线框、3/4 / 前 / 后 / 侧 / 俯视、拆解与复位。它是几何示意，不是精确 CAD 或实时数字孪生。线框不会表示管理总线；拆解不会改变 CSR。

## 方向 B：AI 执行与人工协作

| 阶段 | AI 的产品目标 | 用户可做什么 | 需要呈现的证据 |
| --- | --- | --- | --- |
| 确认任务 | 整理交付目标、输入和授权范围 | 修改目标、确认范围 | 资料版本与缺失项 |
| 核对连接 | 对比旧配置与新资料 | 围观、查看依据 | 不一致的字段与来源 |
| 等待决策 | 停止有歧义的写入 | 采用建议、暂缓、接管 | 建议值、影响范围 |
| 人工接管 | 暂停对同一配置写入 | 修改总线与依据，保存或取消 | 控制权、未提交草稿 |
| 重新校验 | 校验用户确认后的候选配置 | 审阅差异；失败时返回修改 | 通过 / 失败 / 未执行分别展示 |
| 生成候选包 | 构建可追溯交付物 | 确认后出包，查看未完成验证 | 清单、版本、报告及部署边界 |

原型不运行真实 AI。以“演示：AI 核对资料”“模拟校验”“模拟生成候选包”等按钮推进状态；只有连接一致性按示例规则判断，其余检查明确标记为预设或未执行。

## 低保真页面与信息优先级

1. 任务启动：两条设计方向、任务目标、输入资料、授权边界和一个主入口。
2. 可视化协作：左侧可收起步骤与部件树，中间可同时打开的物理 / 拓扑 / 草稿窗口，右侧任务记事板。
3. 校验与审阅：差异、依据、校验结果和明确的出包确认。失败时禁止出包。
4. 出包结果：交付清单、决策记录、未验证项。只允许下载带 demo 标识的 JSON 记录，不伪造可部署包。

始终优先显示当前任务、当前步骤、操作权和待决策事项。输入证据与详细边界折叠展示；任务记录随真实原型操作追加。

## 评审时建议走两条路径

### 路径一：接受建议

开始任务 → AI 核对资料 → 拆解整机 / 进入板卡 / 切换视角 → 查看 CSR 拓扑 → 采用资料建议 → 模拟校验 → 审阅勾选 → 生成候选结果 → 下载演示记录。

### 路径二：接管与失败恢复

开始任务 → AI 核对资料 → 接管 → 保留 I2C-7 并填写依据 → 保存交还 → 模拟校验失败、出包禁用 → 返回修改 → 接管改为 I2C-6 并填写新依据 → 校验通过 → 审阅后生成候选结果。

另检查：取消编辑不保存、资料不足可暂缓、未填写依据不可保存、步骤折叠后画布填充、实体 / 线框切换不改配置、回到记事板保留记录。

## 工程化前必须补齐

- 真实硬件资料、文件版本与对象模型；标出资料可信度和适用机型。
- 三维部件标识到 CSR 对象 / 源文件的映射，缺失时提供降级入口。
- AI 执行接口与真实工具事件，不用前端预设文字冒充执行。
- 草稿版本、写入锁、接管冲突检测、撤销和持久化恢复。
- 真实校验器、构建器、签名服务、设备验证和权限审批。
- 与已有首页当前任务卡片的正式接入。本次单独输出原型，不覆盖已发布首页。
