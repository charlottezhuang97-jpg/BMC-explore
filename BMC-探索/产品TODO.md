### 首条演示链路

CSR 出包任务 → AI 提出风扇板管理连接待确认项 → 用户打开整机检查器 → 高亮风扇板并拆解查看 → 切换 CSR 拓扑 → 围观或接管配置草稿 → 交还 AI 校验 → 结果返回任务记事板。

示例连接参数仅作占位，真实地址、总线和映射必须来自对应型号资料，不能由模型外观推断。

### 验收标准与边界

- [ ] 用户始终知道当前任务、选中部件、当前操作主体及配置是否已经生效。
- [ ] 线框仅展示几何边缘，不冒充 I²C 等电气 / 管理连线。
- [ ] 物理拆解不会改变管理拓扑；移动模型不会改变真实硬件接线。
- [ ] 围观不能写入配置；接管产生可审阅的差异，能取消草稿；部署须另行确认。
- [ ] 没有模型或对象映射时明确提示，不伪造精确位置、连线或实时状态。
- [ ] 3D 加载失败时保留部件树和配置入口，不能整个页面空白。
- [ ] 不替代工作台任务首页，不在首版承诺任意器件替换、自由拼装或 PCB 布局布线。

## AGENT-02｜AI 辅助部件适配到整机集成

- 状态：用户已同意先细化 CSR 适配与出包，已生成低保真；PSR 整机集成及领导期望的完整自动化范围仍待确认。
- 输入：用户转述领导观看 AI 在 KiCad 中进行电路板布局布线的示例后，希望 BMC 研发也能达到类似的 AI 操作深度。
- 核心区分：该示例是“原理图 → PCB 布局布线”，不等于“CSR → PSR”。可借鉴的是 AI 操作专业工具、产出工程文件、接受检查与人工介入的工作方式。
- 候选产品目标：AI 根据已有硬件资料和工程约束，辅助完成部件 CSR 配置、跨板管理连接核对、PSR 及相关机型配置、构建和验证。

### 建议拆分

- [ ] 第一阶段：单块板卡的 CSR 适配 / 修改 / 校验 / 出包。输入资料、工具支持和验收规则齐备后才允许自动执行。
- [ ] 第二阶段：多个部件的整机集成，核对 Connector / Anchor 管理连接、整机 PSR 规则及必要的机型软件配置；并非将多个 CSR 简单合并成 PSR。
- [ ] 第三阶段：接入授权测试环境，部署候选配置、验证识别与监控结果、记录证据；写入、重启和部署等动作按权限确认。
- [ ] 全过程：AI 任务记事板记录进度、输入来源、缺失资料、人工决策和校验结果；用户可围观、接管和交还任务。
